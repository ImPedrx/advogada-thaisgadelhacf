# Thaís Gadelha · Advogada (Direito Cível e Público)

Landing page da advogada Thaís Gadelha (Thais Gadelha Carvalho), TG Advocacia: sucessões, regularização de imóveis e estratégia processual. Atendimento na Aldeota, Fortaleza-CE, e consultoria on-line.

React + Vite + Tailwind v4, animações com Motion. Componentes de [React Bits](https://reactbits.dev) (RotatingText, ShinyText, SpotlightCard, CurvedLoop, SplitText, Magnet), botão inspirado no Uiverse e `Pillars` (fundo de linhas com feixes, no estilo dos "background beams" do 21st.dev) próprio. Pensado primeiro para o celular.

```bash
npm install
npm run dev     # http://localhost:5173
npm run build   # gera dist/
```

Conteúdo editável (OAB, WhatsApp, áreas, etapas, situações, FAQ) em `src/content.ts`. Fontes: Google Maps, facebook.com/thaisgadellha e currículo no Escavador.
Fotos em `public/img/`, tiradas do Facebook dela: `thais-hero.jpg` (texto do post removido) e `thais-sentada.jpg` (recorte de um card). Originais em `../photos/`.

Antes de publicar, confirmar com a cliente: número da OAB (obrigatório, Provimento 205/2021), áreas de atuação, endereço/horário e se usa o (85) 99620-2000 do Facebook.
